# ARAM Lite

基于 [Sona](https://github.com/WJZ-P/sona) 的个人用精简 Pengu 插件。

将 plugin 目录内全部文件复制到 Pengu/plugins/任意文件夹名/，按 Ctrl+Shift+R 刷新客户端。入口为 index.js，无需安装包。

点击客户端右下角版本号上方 **ARAM 设置** 或按 **F8** 打开面板，Esc 关闭。支持各功能独立开关、接受/回房延迟、点赞类型；更改自动保存，可恢复默认。“记住召唤师技能”默认开启，恢复默认也会开启。关闭时默认闪现 / 雪球；开启时按英雄保存并恢复技能，无记录仍使用闪现 / 雪球。开关在下次选人应用，不覆盖当前场次的手动修改。

功能：自动接受、ARAM Bench 无 CD 换英雄、默认闪现和雪球 / 按英雄记忆技能、选人退出、自动点赞一名队友（优先开黑队友，否则选择其他可点赞队友）、独立开关的原生图表自动打开与延时回房、好友模式/时间/同局标记、空闲时 Play 直建海克斯大乱斗房间（queueId 2400）、DOM 自愈。

Bench 交换仍受服务端校验；同局标记不等于确定预组队。中途加载到已有选人时，跳过当前场次的技能初始化。

开发命令（Node.js + npm）：

    npm ci
    npm test
    npm run build

src 为源码，.build 为构建脚本、测试及本地工具，plugin 为运行文件。无 React 或运行时依赖。已通过模拟测试，尚未在真实客户端中验收。

对局结束的三个开关独立：自动点赞、自动打开统计（点赞完成后进入图表）、自动回房。回房延迟从结算/点赞界面首次出现计时，不等待图表；15000 毫秒即 15 秒。

开启自动回房时，界面中心下方显示倒计时；点击“取消本局回房”只取消当前局，下局自动恢复，不影响点赞和统计。

好友状态增强显示大厅、排队、选人、游戏中、观战和回放等状态及模式；对局计时仅用于游戏中/观战，未知或空闲状态保留客户端原文。好友结算状态未公开，无法可靠识别。
